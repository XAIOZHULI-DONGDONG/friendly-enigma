# Shadowrocket Subscription

Daily-updated Shadowrocket subscription: 5 free US nodes, tested for
TCP reachability before each update.

## Subscribe (Shadowrocket)

Add this subscription URL in Shadowrocket (once). The node list
refreshes automatically every morning:

https://raw.githubusercontent.com/XAIOZHULI-DONGDONG/friendly-enigma/main/subscription.txt

## What is in here

- `subscription.txt` — base64-encoded list of node URIs (one per line
  when decoded). Standard Shadowrocket subscription format.
- Updated every morning (~08:45 CST) from public free-node sources
  (leidahub.top, v2raydog). Only public free nodes are ever included.

## What is NOT in here

No private credentials, no passwords, no API keys, and no personal
server nodes. The owner's own Cloady node is deliberately NOT in
this subscription.
